# David Movies (MvcMovie)

ASP.NET Core MVC app built from the Microsoft MVC tutorial series.

## Additional functionality
- App title changed to David Movies
- Added my own favorite movies
- Listing heading changed to My Movies
- From year filter (that year or newer)
- Padding added to input, select and textarea in wwwroot/css/site.css

## Run
dotnet run
(If the database is missing: dotnet ef database update)
